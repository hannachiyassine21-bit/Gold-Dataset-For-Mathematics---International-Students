### Correction SEQ07

To check for convergence, evaluate the absolute value of the sequence terms:
$$|u_n| = \left| \frac{(-1)^n}{n^2 + 1} \right| = \frac{1}{n^2 + 1}$$

Now, compute the limit of the absolute value expression:
$$\lim_{n \to +\infty} |u_n| = \lim_{n \to +\infty} \frac{1}{n^2 + 1} = 0$$

**Conclusion:** Since the limit of the absolute value is $0$, the sequence $(u_n)$ converges, and its limit is $0$.
